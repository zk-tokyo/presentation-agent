Speaker Notes:
World ID の全体構成と、その匿名性機構を 1 枚で扱う。World ID は 1 つの暗号ではなく、複数プリミティブの合成である点を示したうえで、発行後の利用を守るプライバシー層（Semaphore + nullifier）まで一気に見せる。
【パイプライン】① Orb が虹彩をスキャン（専用 HW で人間性と一意性を取得。写真は実機 Orb / Tools for Humanity）→ ② iris code 化（生の虹彩画像は破棄し、一意性判定用の特徴コードのみ残す）→ ③ 一意性チェック = MPC（iris code を複数ノードへ秘密分散し、平文を誰も見ずに既登録集合と照合。~18M users で本番）→ ④ 計算の検証可能性 = co-SNARK（MPC ノードが「照合を正しく計算した」証明を同時生成し、semi-honest から maliciously secure・公開検証可能へ格上げ。TACEO:Proof として 2025-07 本番化）→ ⑤ 匿名クレデンシャル = Semaphore（メンバーシップ証明 + nullifier で身元を隠したまま「検証済み人間」を示し、二重使用を防止）。
【強調点】③の MPC が土台で、④の co-SNARK はそこに「正しさの公開検証」を足す層。両者を混同しない（CLAUDE.md §9 の学術的厳密さ）。合成の中核 ④ co-SNARK は後続スライドで深掘りする。
【発行後のプライバシー（旧 P23 を統合）】Semaphore は zk-SNARK ベースのグループ・メンバーシップ証明。各ユーザーは identity commitment を Merkle tree に登録し、「自分はこの木のどれかの葉（=検証済み人間）」を、どの葉かを明かさず匿名に証明する。nullifier は (user, app, action) の組ごとに決定的に決まる値で、同じ文脈では常に同じだが別文脈や identity commitment とは結び付けられない → アプリは「1 人 1 アクション（二重投票/重複登録の防止）」を、誰かを特定せずに強制でき、アプリ横断トラッキングも防げる。World ID 4.0 では分散 OPRF ネットワークで nullifier を計算し、one-time-use nullifier やリカバリ等を導入。生体認証ゆえ各国の privacy 規制（停止命令等）の議論が続く点も触れる。語彙は「匿名性 = ZK メンバーシップ」「二重使用防止 = nullifier」をセットで覚える。
