# 任意のデータ形式を相互変換する汎用アダプタ

<div class="flex justify-center mt-3">
<img src="/images/pc1_universal_adapter.png" class="max-h-[330px] rounded-xl border border-gray-200" alt="Universal Cryptographic Adapter" />
</div>
