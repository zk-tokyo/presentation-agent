Speaker Notes:
Programmable Cryptography の核心: プリミティブは目的指向で組み合わせられる。6 枚はすべて実在するシステム名であり、うち 4 つは本講義で深掘りする。
① Longfellow = ZK ∘ ECDSA(mDOC)（既存 ID 標準を作り直さず ZK 化）｜ ② Verifiable FHE = ZK + FHE（計算委託 + 計算の正しさ。後半で深掘り）｜ ③ threshold FHE = MPC + FHE（計算委託 + 復号鍵の分散。Zama）｜ ④ POD2 = ZK + 署名データ（署名済みデータを証明可能にして演繹で積み上げる。最終盤で深掘り）｜ ⑤ leanVM = ZK + XMSS（耐量子署名を再帰集約。この直後の zkVM パートで深掘り）｜ ⑥ co-SNARK = ZK + MPC（正しさ + 入力秘匿。World ID で深掘り）。
各行は「A が保証 + B が秘匿/補完」の形。合成を設計する鍵は「A は何を保証し B は何を秘匿するか」を分解すること。次のフローチャートはこの分解を自動化する道具。
