# ZK / MPC / FHE のおさらいと比較

<div class="text-sm text-gray-500 mt-1 mb-3">Week 1-5 で学んだ 3 つの道具を、「何を守り・誰が計算し・誰が検証するか」で捉え直す。</div>

<table class="text-sm">
<thead>
<tr>
<th class="w-1/6"></th>
<th>守るもの</th>
<th>信頼前提</th>
<th>コスト特性</th>
<th>合成性</th>
</tr>
</thead>
<tbody>
<tr>
<td><div class="font-black text-amber-700">ZK</div><div class="text-xs text-gray-500 leading-tight">正しさを witness なしで証明</div></td>
<td>prover の証言 (witness)</td>
<td>計算上の困難性 (DLP / pairing / hash)。prover 1 名</td>
<td>証明生成は重い / verify は軽い</td>
<td>recursion / aggregation で重ねやすい</td>
</tr>
<tr>
<td><div class="font-black text-amber-700">MPC</div><div class="text-xs text-gray-500 leading-tight">入力を秘匿して共同計算</div></td>
<td>各参加者の入力</td>
<td>閾値以下の party の collusion 想定。online は対話的</td>
<td>各 party 軽い / 通信ラウンド数が支配</td>
<td>静的合成は可、動的合成は protocol 依存</td>
</tr>
<tr>
<td><div class="font-black text-amber-700">FHE</div><div class="text-xs text-gray-500 leading-tight">暗号文のまま計算を委託</div></td>
<td>計算データ・中間状態</td>
<td>LWE 困難性。鍵管理者の信頼 (Threshold FHE で分散可)</td>
<td>暗号文上演算は重い / bootstrapping が支配</td>
<td>暗号文同士は自然合成、結果検証は別途</td>
</tr>
</tbody>
</table>

<div class="mt-4 text-sm text-gray-700 text-center max-w-5xl mx-auto">各セルは「<strong>無料ではない</strong>」対価。<strong class="text-amber-700">組み合わせれば全部解決</strong>は誤りで、目的に応じて選び・合成する。</div>
