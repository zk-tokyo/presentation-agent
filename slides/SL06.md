# 設計フローチャート

<div class="text-sm text-gray-500 mt-1 mb-2">要件 (何を秘匿 / 誰が計算 / 誰が検証) を入れると、必要な primitive と合成が決まる。</div>

```mermaid {scale: 0.5}
flowchart TD
  R["要件<br/>何を秘匿 / 誰が計算 / 誰が検証"] --> Q1{"計算の正しさを<br/>公開検証したい?"}
  Q1 -->|はい| Q2{"秘匿入力を<br/>誰が持つ?"}
  Q1 -->|いいえ| Q3{"暗号文のまま<br/>計算を委託?"}
  Q2 -->|単独 prover| ZK["ZK / zkVM"]
  Q2 -->|複数者が持ち寄る| COS["co-SNARK<br/>ZK + MPC"]
  Q2 -->|耐量子署名を集約| LEAN["leanVM<br/>XMSS + ZK"]
  Q3 -->|はい| Q4{"その計算の<br/>正しさも必要?"}
  Q3 -->|いいえ| Q5{"複数者で<br/>共同計算?"}
  Q4 -->|はい| VFHE["vFHE<br/>ZK + FHE"]
  Q4 -->|いいえ| FHE["FHE / PIR"]
  Q5 -->|はい| MPC["MPC"]
  Q5 -->|いいえ| NONE["暗号は不要かも<br/>要件を見直す"]
  classDef p fill:#fffbeb,stroke:#f59e0b,color:#111;
  classDef n fill:#f9fafb,stroke:#9ca3af,color:#555;
  class ZK,COS,LEAN,VFHE,FHE,MPC p; class NONE n;
```
