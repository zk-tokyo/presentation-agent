# グループワーク① 回答例：暗号文のまま AI 診断

<div class="text-sm text-gray-500 mt-1 mb-4">生データを渡さず、診断の<strong>正しさ</strong>まで確認する。<strong class="text-amber-700">Verifiable FHE = FHE + ZK</strong> が両方の要件を同時に満たす。</div>

<div class="flex items-stretch justify-center gap-2 max-w-6xl mx-auto">

<div class="flex-1 p-4 bg-green-50 rounded-xl border border-green-200">
<div class="text-[10px] font-bold tracking-widest text-gray-400 mb-1">① ユーザ（患者）</div>
<div class="text-md font-black text-gray-900 mb-2">暗号化して送る</div>
<div class="text-sm text-gray-700 leading-relaxed">医療データ <strong>D</strong> を FHE 公開鍵で暗号化し <strong>Enc(D)</strong> だけをクラウドへ。<span class="text-gray-500">生データ D はローカルに留まる。</span></div>
</div>

<div class="flex items-center text-2xl text-amber-500 font-black px-1">&#9654;</div>

<div class="flex-1 p-4 bg-amber-50 rounded-xl border border-amber-200">
<div class="text-[10px] font-bold tracking-widest text-gray-400 mb-1">② クラウド AI</div>
<div class="text-md font-black text-gray-900 mb-2">暗号文のまま推論</div>
<div class="text-sm text-gray-700 leading-relaxed">暗号文のまま推論 <strong>f</strong> を評価し <strong>Enc(f(D))</strong> を返す。同時に「c に正しく f を評価した」<strong>証明 π</strong> を生成。</div>
</div>

<div class="flex items-center text-2xl text-amber-500 font-black px-1">&#9654;</div>

<div class="flex-1 p-4 bg-blue-50 rounded-xl border border-blue-200">
<div class="text-[10px] font-bold tracking-widest text-gray-400 mb-1">③ ユーザ（検証）</div>
<div class="text-md font-black text-gray-900 mb-2">復号 + 検証</div>
<div class="text-sm text-gray-700 leading-relaxed">Enc(f(D)) を復号して診断結果を得る + <strong>π を検証</strong>。<strong>データ機密</strong>（FHE）と<strong>計算の正しさ</strong>（ZK）を同時に確認。</div>
</div>

</div>

<div class="mt-5 p-4 bg-gray-50 rounded-xl border border-gray-200 max-w-6xl mx-auto text-sm text-gray-700 space-y-1.5">
<div><span class="text-amber-600 font-black mr-1">信頼境界</span>クラウドは信頼しない。境界を越えるのは <strong>Enc(D)</strong> と <strong>Enc(f(D)) + π</strong> だけ。生データ・診断結果はローカル。</div>
<div><span class="text-amber-600 font-black mr-1">なぜこの組み合わせ</span>FHE 単体は<strong>データ機密のみ</strong>で「正しく計算したか」は保証しない → ZK を重ねた <strong>Verifiable FHE</strong> で埋める。MPC / TEE は信頼前提とコストで不利。</div>
<div><span class="text-red-600 font-black mr-1">落とし穴</span>性能（FHE の bootstrapping が支配的）／ soundness（Verifiable FHE の回路バグ）／ メタデータ（誰がいつ診断したかは隠れない）／ 規制（医療データ = GDPR・HIPAA）。</div>
</div>

<div class="absolute bottom-3 left-6 text-[10px] text-gray-400 leading-tight max-w-3xl">
Sources: Verifiable FHE = FHE + ZK（クラウドが暗号文評価の正しさを証明）｜ 本講義 SL（FHE / Verifiable FHE）
</div>
