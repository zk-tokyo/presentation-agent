# World ID のプライバシー：Semaphore と nullifier

<div class="text-sm text-gray-500 mt-1 mb-4">身元を明かさずに「検証済みの人間である」ことだけを示す。鍵は <strong>ZK メンバーシップ証明（Semaphore）</strong>と <strong>nullifier</strong>。</div>

<div class="grid grid-cols-3 gap-4 max-w-6xl mx-auto">
<div class="p-4 bg-white rounded-xl border border-gray-200 shadow-sm">
<div class="text-md font-black text-gray-900 mb-2">メンバーシップ証明</div>
<div class="text-sm text-gray-700 leading-relaxed"><strong>Semaphore</strong>（zk-SNARK）で「検証済み人間の Merkle tree に属する」ことを<strong>匿名で</strong>証明。どの人かは明かさない。</div>
</div>
<div class="p-4 bg-white rounded-xl border border-gray-200 shadow-sm">
<div class="text-md font-black text-gray-900 mb-2">nullifier</div>
<div class="text-sm text-gray-700 leading-relaxed">(user × app × action) ごとに<strong>決定的</strong>だが他と<strong>紐付け不可</strong>。アプリは「1 人 1 アクション」を、本人を知らずに強制できる。</div>
</div>
<div class="p-4 bg-amber-50 rounded-xl border border-amber-200">
<div class="text-md font-black text-gray-900 mb-2">効果</div>
<div class="text-sm text-gray-700 leading-relaxed">アプリ横断の<strong>トラッキングを防止</strong>。同じ人でも別アプリの行動は結び付かない。</div>
</div>
</div>

<div class="mt-4 p-3 bg-gray-50 rounded-xl border border-gray-200 max-w-6xl mx-auto text-sm text-gray-800">
<span class="text-amber-600 font-black mr-1">&#9654;</span><strong>World ID 4.0</strong>：分散 OPRF ネットワークで nullifier を計算、one-time-use nullifier、リカバリ等で一意性とプライバシーを強化。<span class="text-gray-500">留意点：生体情報の扱いは各国で規制議論が継続。</span>
</div>

Speaker Notes:
World ID のプライバシー機構。
【メンバーシップ証明】Semaphore は zk-SNARK ベースのグループ・メンバーシップ証明。各ユーザーは identity commitment を Merkle tree に登録し、「自分はこの木のどれかの葉である(=検証済み人間)」を、どの葉かを明かさずに証明する。
【nullifier】(user, app, action) の組ごとに決定的に決まる値。同じ文脈では常に同じ nullifier だが、別文脈の nullifier や identity commitment とは結び付けられない。これによりアプリは「1 人 1 アクション(二重投票/重複登録の防止)」を、誰かを特定せずに強制できる。
