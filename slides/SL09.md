# B. vFHE ①

<div class="grid grid-cols-3 gap-4 mt-4 max-w-6xl mx-auto">
<div class="p-4 bg-amber-50 rounded-xl border border-amber-200">
<div class="text-md font-bold text-amber-700 mb-1">① vFHE <span class="text-xs font-normal text-gray-500">(本講義の対象)</span></div>
<div class="text-sm text-gray-700"><code>Eval(ct, f) → ct_out</code> の<strong>正当性を ZK 証明</strong>。サーバーが嘘の演算をしていない検証</div>
</div>
<div class="p-4 bg-white rounded-xl border border-gray-200 shadow-sm">
<div class="text-md font-bold text-gray-700 mb-1">② Verifiable decryption</div>
<div class="text-sm text-gray-700">正しい鍵で正しく復号した証明 <span class="text-gray-400">(脚注扱い)</span></div>
</div>
<div class="p-4 bg-white rounded-xl border border-gray-200 shadow-sm">
<div class="text-md font-bold text-gray-700 mb-1">③ 広義 ZK+FHE composition</div>
<div class="text-sm text-gray-700">暗号文上演算 + 入力の真正性検証 <span class="text-gray-400">(例: PSE zkFHE)</span></div>
</div>
</div>

<div class="mt-2 text-[11px] text-gray-500 max-w-6xl mx-auto">FHE の信頼前提は「<strong>データ機密のみ。計算正しさは vFHE で別途</strong>」と分解する。</div>
