# **Blind Rotation** 
暗号文の状態でのテスト多項式の回転



## 平文の状態での$x^{-b+\mathbf{as}}v\;\text{mod}\;x^n+1$の求め方

$\mathbf{a}=\left(a_0,a_1,\ldots,a_{k-1}\right),\mathbf{s}=\left(s_0,s_1,\ldots,s_{k-1}\right)$とすると、$\mathbf{as}=\Sigma_{i=0}^{k-1}a_is_i$と表せる。  
$x^{-b+\mathbf{as}}v=x^{-b+\Sigma_{i=0}^{k-1}a_is_i}v=x^{a_{k-1}s_{k-1}}\left(x^{-b+\Sigma_{i=0}^{k-2}a_is_i}v\right)$ より、$Q_k:=x^{-b+\Sigma_{i=0}^{k-1}a_is_i}v$は$\ Q_0=x^{-b}v$として次の漸化式から求められる。    
$Q_{j+1}=x^{a_js_j}Q_j=\left\{\begin{matrix}Q_j\;\;\;\;\text{ if }\ s_j=0\\x^{a_j}Q_j\text{ if } s_j=1\end{matrix}\right.$  

  よって$x^{-b+\mathbf{as}}v\;\text{mod}\;x^n+1$は以下のアルゴリズムから計算できる
- $Q_0 \gets x^{-b}v$
- for $j=0\dots k-1$
	- $Q_{j+1} \gets \text{MUX}(s_j, Q_j, x^{a_j}Q_j)$
- return $Q_k\;(=x^{-b+\mathbf{as}}v)$
  
これを準同型演算で記述する。

必要なもの
- MUXを暗号文のまま実行するCMUX
- $s_j$を暗号化するRGSW
- 多項式である$v$を暗号化するRLWE
